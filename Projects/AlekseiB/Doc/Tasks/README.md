# Tasks

Purpose:
- Implementation tasks for developers and AI agents.
- Holds task notes, plans, and completion criteria for work in progress.

Rules:
- Create a task note here for every task-based change before editing code.
- Each task note states the goal, the affected areas, the acceptance criteria, and the validation performed.
- Reference the feature document from `Doc/Features` that the task implements.
- Record the outcome of finished tasks instead of deleting them.

Update policy:
- Update this document when project behavior, architecture, dependencies, or workflow changes.

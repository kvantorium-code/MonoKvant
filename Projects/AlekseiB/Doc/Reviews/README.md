# Reviews

Purpose:
- Results of code review and agent review.
- Quality remarks, found issues, and accepted risks.

Rules:
- Store every review result here, including reviews of agent-generated code.
- Each review states the reviewed scope, the findings ordered by severity, and the agreed follow-up actions.
- Link follow-up implementation work to `Doc/Tasks`.
- Do not edit an existing review after the fact; add a new review that references the old one.

Update policy:
- Update this document when project behavior, architecture, dependencies, or workflow changes.

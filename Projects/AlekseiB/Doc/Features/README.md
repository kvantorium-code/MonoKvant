# Features

Purpose:
- Describes implemented and planned game features.
- One document per feature, stored in this folder.
- Feature documents describe observable behavior, not implementation details.

Rules:
- Add a document here before changing the behavior of an existing feature.
- Keep each feature document self-contained and up to date with the actual implementation.
- Cross-reference the relevant ADR files from `Doc/ADR` when a feature relies on an architectural decision.
- Implementation tasks derived from a feature belong in `Doc/Tasks`.

Update policy:
- Update this document when project behavior, architecture, dependencies, or workflow changes.

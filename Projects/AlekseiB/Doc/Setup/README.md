# Setup

Purpose:
- Local setup instructions, SDK integration, MCP connection, and build pipeline notes.

Rules:
- Keep setup instructions reproducible from a clean clone.
- Document the exact Unity editor version required by the project.
- MCP for Unity is installed as a Unity package; further client configuration is performed in the Unity Editor window `MCP for Unity`.
- Never commit generated IDE or build artifacts.

Local requirements:
- Unity `6000.5.3f1`.
- Render pipeline: Universal Render Pipeline.

Unity MCP package:
- Source: `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`
- Package name: `com.coplaydev.unity-mcp`
- Installed version: `10.2.0`
- Requires Unity 2021.3 or newer.
- Install through `Window -> Package Manager`, or add the git URL to `Packages/manifest.json`.
- After the package is installed and the project compiles, open `Window -> MCP for Unity` and configure the connection there.
- Menu path is defined by the package as `Window/MCP for Unity` (shortcut `Ctrl+Shift+M`).
- MCP client configuration is not automated in this repository.

### Troubleshooting: `No 'git' executable was found`

A git URL package fails to resolve with this error in the Unity log:

```text
An error occurred while resolving packages:
    com.coplaydev.unity-mcp: No 'git' executable was found.
    Please install Git on your system then restart Unity and Unity Hub
```

Cause and fix:
- Unity Package Manager clones git packages by invoking `git`, so `git` must be on the `PATH` of the **running** Unity and Unity Hub processes.
- A stale environment is the usual cause: Unity or Unity Hub was started before Git was installed, so the process inherited an old `PATH` even though the persisted variable is already correct.
- No system change is needed if `git` is already on the persisted `PATH`. Fully close Unity **and** Unity Hub, then relaunch.
- Check what a process can see with `Get-Command git`; check the persisted value with `[Environment]::GetEnvironmentVariable('Path','User')`.
- Verify success by confirming an entry for `com.coplaydev.unity-mcp` in `Packages/packages-lock.json` and a matching folder in `Library/PackageCache/`.

# 06. Локализация и сохранение прогресса

Статус: todo · Зависит от: 05 · Блокирует: 07

## Цель

Убрать захардкоженные строки из UI и сохранять прогресс игрока между сессиями.

## Часть A. Локализация (`Scripts/Localization`)

- [ ] `LocalizationKeys` — константы ключей (`hud.score`, `hud.birds`, `result.win`, `result.lose`, `menu.play`, …).
- [ ] `ILocalizationService`/`LocalizationService`: `Get(key)`, `Get(key, args)`, смена языка, событие `LanguageChanged`.
      Источник — простой ScriptableObject-словарь (en/ru), без внешних пакетов.
- [ ] `LocalizedText` — компонент для TMP, сам подписывается на смену языка.
- [ ] Заменить строки в презентерах/префабах (`"SCORE  "`, `"BIRDS  "`, `"LEVEL CLEARED"`, `"TRY AGAIN"`, `"NEXT LEVEL"`, …).
- [ ] Регистрация в `ProjectLifetimeScope`.
- Правило слоя: только адаптеры и ключи, никакой бизнес-логики.

## Часть B. Прогресс

- [ ] `IProgressService`/`ProgressService`: лучшие очки и звёзды по уровню, разблокированные уровни.
- [ ] Хранилище: `PlayerPrefs` с JSON за интерфейсом `IProgressStorage` (легко заменить позже).
- [ ] Запись результата в `ResultState` при победе (только если лучше предыдущего).
- [ ] `LevelSelectScreen` показывает звёзды и блокирует недоступные уровни.

## Критерии приёмки

- [ ] Смена языка в рантайме обновляет все видимые тексты.
- [ ] Результат уровня сохраняется и переживает перезапуск Play Mode/билда.
- [ ] В коде UI нет строковых литералов с пользовательским текстом.
- [ ] Console: 0 ошибок, 0 предупреждений.
